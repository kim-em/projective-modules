# API guides

- [Mathematical overview](Overview.md): result families, hypotheses, examples and limits.
- [Mathematical API guide](API.md): selected interfaces, signatures,
  characteristic formulas, canonical dependencies and links to defining modules.
- [Countably generated submodules over Noetherian rings](NoetherianSubmodule.md):
  a focused guide to the countable-generation theorem and its use.

The mathematical API guide includes the semiring-level split-kernel API and
the chosen projective-complement construction over rings. Consult the
[current Lean sources](../ProjectiveModules/) for authoritative declaration
types and definitions, with their namespace, universe and instance context.

These guides are not an exhaustive catalogue of exported names, a
machine-generated account of the whole current API, or a proof or
source-coverage certificate.
